# Log File Analyzer (Python)

## Description
This project reads a log file, counts INFO, WARNING, and ERROR messages, 
and generates a ranking of the most frequent errors. Results are saved in a CSV file.

## Features
- Counts total INFO, WARNING, ERROR messages
- Generates ranking of error messages
- Exports results to CSV
- Clean, modular code with functions

## Files
- main.py → main script
- system.log → sample log file
- errors_summary.csv → generated summary

## How to run
```bash
python main.py
